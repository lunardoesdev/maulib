# mewnet

A proxy core that runs **inside your process**: [mihomo](https://github.com/MetaCubeX/mihomo)
v1.19.33 behind a small C ABI. No daemon, no control port, no JSON.

The API you normally use is **maunet**: global state, and everything is a link id.
You build one shared library, call `InitMaunet`, add links or subscriptions, pick
the default link, and your program sends traffic through `127.0.0.1:<port>`.

```c
maunet_settings s = MaunetSettingsDefault();
s.db_path = "data/app.db";
InitMaunet(&s);

int64_t id = AddMaunetLink("vless://...").id;
SetMaunetLinkAsDefault(id);
/* http://127.0.0.1:<GetMaunetProxyPort()> now exits through that link */

DeinitMaunet();
```

## Build the library

Two things are needed: Go 1.26+ with CGO and a C compiler (`gcc` or `clang`).
With [mise](https://mise.jdx.dev): `mise install go@1.27.3`.

```bash
cd libs/mewnet
CC=gcc CGO_ENABLED=1 go build -p=1 -trimpath -buildmode=c-shared \
  -ldflags "-s -w -X github.com/metacubex/mihomo/constant.Version=v1.19.33" \
  -o ../../dist/libmewnet.so ./cmd/mewnet
cd ../..
```

That is the whole build. It produces:

```text
dist/libmewnet.so                  the library (Go core + C API + SQLite)
dist/libmewnet.h                   header generated by cgo (ignore it)
libs/mewnet/cmd/mewnet/maunet.h    the API you include
libs/mewnet/cmd/mewnet/mewnet*.h   what maunet sits on
```

The first build downloads the mihomo modules and takes a few minutes; later
builds are incremental. `-p=1` keeps memory use low — mihomo is large.

## Your first program

`hello.c`:

```c
#include <stdio.h>
#include "maunet.h"

int main(void) {
    maunet_settings settings = MaunetSettingsDefault();
    settings.db_path = "data/hello.db";   /* created and migrated on init */
    settings.mixed_port = 18085;          /* 0 = any free port, -1 = no inbound */
    settings.run_agent = true;            /* keep a working link in the background */

    if (!InitMaunet(&settings)) {
        fprintf(stderr, "init: %s\n", GetMaunetError());
        return 1;
    }

    /* A subscription is a source of links; a single link can be added directly. */
    maunet_link_result sub = AddMaunetSubscription("https://example.com/sub.txt");
    printf("subscription %lld, %lld links\n", (long long)sub.id,
           (long long)GetMaunetLinkCount());

    maunet_link_result manual = AddMaunetLink("vless://...");
    if (manual.id > 0 && SetMaunetLinkAsDefault(manual.id)) {
        printf("use http://127.0.0.1:%d through %s\n", GetMaunetProxyPort(),
               GetMaunetLink(manual.id).name);
    }

    /* Measure one link; alive, delay and rating are stored with it. */
    if (!TestMaunetLink(manual.id)) {
        printf("link is not usable: %s\n", GetMaunetError());
    }

    maunet_status status = GetMaunetStatus();
    printf("%lld links, %lld alive, selected %s\n", (long long)status.links,
           (long long)status.alive, status.selected);

    DeinitMaunet();
    return 0;
}
```

Build and run it:

```bash
cc hello.c -Ilibs/mewnet/cmd/mewnet -Ldist -lmewnet \
   -Wl,--allow-shlib-undefined -Wl,-rpath,'$ORIGIN' -o dist/hello
./dist/hello
```

(`'$ORIGIN'` makes the binary look for `libmewnet.so` next to itself. From
another directory use `LD_LIBRARY_PATH=dist ./hello` instead.)

While the program runs, anything can use the proxy:

```bash
curl -x http://127.0.0.1:18085 https://www.gstatic.com/generate_204   # 204
curl -x http://127.0.0.1:18085 https://api.ipify.org                   # exit IP
```

## How it works

```text
AddMaunetLink / AddMaunetSubscription
                │  every link is one row in SQLite and gets an id
                ▼
          link id ──SetMaunetLinkAsDefault──► selected link in the core
                                                    │
        your app / curl ──► 127.0.0.1:<port> ────────┘
```

- **One hidden instance per process.** `InitMaunet` opens the database, starts
  mihomo and, if asked, the discovery agent. `DeinitMaunet` tears it down.
- **The mixed inbound is the door.** HTTP and SOCKS5 on the same port; traffic
  leaves through the selected link. Switching links is instant for new
  connections, open ones finish on the old link.
- **A link id is the database row id.** It survives restarts, matches what
  `LoadMaunetLinks` returns, and is what every function takes.
- **Subscriptions feed the same table.** Their configs become links with their
  own ids. Links added with `AddMaunetLink` are manual: a subscription refresh
  never removes them.
- **Duplicates never duplicate.** Adding a link that is already stored — same
  text, or the same server and credentials under another name or with different
  transport options — returns the id of the existing link.
- **The agent is optional.** With `run_agent = true` it tests configs, keeps a
  pool of working links and fails over when the active one dies;
  `GetMaunetDefaultLink` follows those switches.

Per-link SOCKS5 endpoints with their own credentials (one exit per consumer)
are a lower-level feature, see [`docs/SHARED_VPN_LINK.md`](docs/SHARED_VPN_LINK.md).

## The API

### Settings

`MaunetSettingsDefault()` fills every field; passing `NULL` or `0` in
`InitMaunet` keeps the default.

| Field | Default | Meaning |
|---|---|---|
| `const char *db_path` | `"data/maunet.db"` | SQLite file, created and migrated |
| `int mixed_port` | `0` | `0` free port, `-1` disabled, `>0` exact |
| `const char *log_level` | `"warning"` | `debug`/`info`/`warning`/`error`/`silent` |
| `const char *user_agent` | `"maunet/0.1"` | HTTP user agent |
| `const char *test_url` | gstatic `generate_204` | what links are tested against |
| `const char *test_expected` | `"204"` | status that counts as success |
| `int test_timeout_ms` | `5000` | per-check timeout |
| `const char *health_url` | `test_url` | what the active link is health-checked with |
| `const char *health_expected` | `test_expected` | expected health status |
| `int health_timeout_ms` | `2500` | health-check timeout |
| `int request_limit` | `10` | shared request budget; `0` disables it |
| `int request_window_seconds` | `240` | budget window |
| `int fetch_interval_sec` | `21600` | subscription refresh interval (6 h) |
| `int pool_target` | `12` | working links the agent keeps |
| `size_t batch` | `70` | configs per discovery batch |
| `size_t concurrency` | `70` | parallel checks in a batch |
| `bool run_agent` | `false` | start the agent with the core (needs an inbound) |

### Lifecycle

- `MaunetSettingsDefault()` — settings with the defaults above.
- `InitMaunet(&settings)` — open the database, start the core and the agent.
- `DeinitMaunet()` — stop everything; safe to call twice.
- `IsMaunetReady()` — true between init and deinit.
- `GetMaunetError()` — message of the last failure, `""` after a success.
- `GetMaunetStatus()` — snapshot struct (below).
- `GetMaunetProxyPort()` — the mixed port, `-1` when the inbound is disabled.

### Links

- `AddMaunetLink(uri)` — store a link, return `{id, error}`; duplicates return
  the existing id.
- `AddMaunetSubscription(url)` — store and fetch a subscription; its configs
  appear as links. The subscription is kept even if the fetch fails.
- `RemoveMaunetLink(id)` / `RemoveMaunetSubscription(id)` — delete.
- `SetMaunetLinkAsDefault(id)` — register the link in the core and select it.
- `GetMaunetDefaultLink()` — id of the selected link, `0` if none; follows the
  agent.
- `TestMaunetLink(id)` — measure through the tunnel, update rating and `alive`.
- `GetMaunetLink(id)` — one `maunet_link_info`.
- `LoadMaunetLinks(limit, offset)` / `UnloadMaunetLinks(list)` — page through
  stored links.
- `GetMaunetLinkCount()` — number of stored links.
- `RefreshMaunetSubscriptions()` — fetch every subscription now.

### Structures

`maunet_link_info`: `id`, `name`, `protocol`, `server`, `port`, `rating`,
`alive`, `manual`, `is_default`, `in_core`, `delay_ms`, `last_error`.

`maunet_status`: `ready`, `agent_running`, `proxy_port`, `links`, `subscriptions`,
`alive`, `default_link`, `default_name`, `selected`.

### Recipes

Find a working link and route through it:

```c
maunet_link_list list = LoadMaunetLinks(100, 0);
for (size_t i = 0; i < list.count; i++) {
    if (TestMaunetLink(list.items[i].id)) {          /* alive + delay stored */
        SetMaunetLinkAsDefault(list.items[i].id);
        break;
    }
}
UnloadMaunetLinks(list);
```

Switch later, by id:

```c
if (SetMaunetLinkAsDefault(other_id)) {
    printf("now exiting through %s\n", GetMaunetLink(other_id).name);
}
```

Keep the selection healthy without writing any logic: set `run_agent = true`.
The agent tests configs in the background and switches when the active link
stops answering; `GetMaunetDefaultLink()` always reports what is in use.

## Under the hood

`maunet` is a thin C façade over **mewnet**, the handle-based API:

- [`mewnet.h`](libs/mewnet/cmd/mewnet/mewnet.h) — instance, proxies, latency
  tests, `SharedVPNLink`, async tasks;
- [`mewnet_subs.h`](libs/mewnet/cmd/mewnet/mewnet_subs.h) — SQLite storage,
  subscriptions, groups, rating, discovery agent;
- [`maunet.h`](libs/mewnet/cmd/mewnet/maunet.h) — everything above, with global
  state and link ids.

Use mewnet directly when you need per-link SOCKS5 endpoints, async task objects,
explicit handle ownership or two isolated instances (the last one is not
possible — mihomo keeps global state). The full handle-based guide, with complete
programs, is [`docs/MEWNET.md`](docs/MEWNET.md); storage details are in
[`docs/SUBSCRIPTIONS.md`](docs/SUBSCRIPTIONS.md).

## Everything else in the repo

Optional binaries built on the same library: `mewnet-cli` (TUI/headless agent),
`mewnet-watch` (discovery only), `mewnet-discovery` (staged discovery probe with
timings), `mewnet-gtk` (GTK4 panel) and `mewnet-gui` (Odin/raylib).

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release -DMEWNET_BUILD_GTK=OFF
cmake --build build -j1
# build/apps/... and the C tests
```

A `Makefile` with shortcuts exists as well (`make build`, `make subs`,
`make test-maunet`), but it is optional — every step above is a plain command.

Windows cross-build of the same library:

```bash
cd libs/mewnet
GOOS=windows GOARCH=amd64 CGO_ENABLED=1 CC=x86_64-w64-mingw32-gcc \
  go build -p=1 -trimpath -buildmode=c-shared \
  -ldflags "-s -w -X github.com/metacubex/mihomo/constant.Version=v1.19.33" \
  -o ../../dist/windows/mewnet.dll ./cmd/mewnet
```

Toolchain notes, flags, cmake options and cross-build details:

## Limitations

- one core instance per process (mihomo keeps global state);
- `dlclose` on the `.so` is not allowed: the Go runtime cannot be unloaded;
- no TUN/system VPN in this build (needs the `with_gvisor` tag);
- "ping" is HTTP latency via `URLTest`, not ICMP;
- per-link SOCKS5 proxies TCP only;
- switching the default link does not migrate connections that are already open;
- `InitMaunet`/`DeinitMaunet` (and `mewnet_init`/`mewnet_close`) must come from
  one thread;
- a panic in a background mihomo goroutine kills the process — run untrusted
  configs in a separate process;
- the build depends on glibc; for old distributions build in an older image.
