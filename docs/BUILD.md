# Building mewnet

## Requirements

| Component | Version |
|---|---|
| Linux | x86_64, glibc |
| Go | 1.27.3 (mise) |
| CGO | clang 23.1.4 (mise) |
| CMake | 4.4.5 (mise) |
| SQLite | vendored amalgamation 3.54.1 |
| Python (tests) | 3.10+ |
| Xray (e2e only) | 26.x |

The mihomo core is pinned in `libs/mewnet/go.mod` (`v1.19.33`). The `main` tag is
not used: it holds a different project.

## Toolchain via mise

Versions are pinned in `.mise.toml`:

```toml
[tools]
go = "1.27.3"
odin = "dev-2026-11a"
android-sdk = "23.0"
clang = "23.1.4"
cmake = "4.4.5"
```

```bash
make deps
# or
mise install
```

Go caches can live outside the home directory:

```bash
export GOPATH="$HOME/.cache/mewnet/gopath"
export GOCACHE="$HOME/.cache/mewnet/gocache"
export GOMODCACHE="$GOPATH/pkg/mod"
```

## Build

```bash
make build
```

Equivalent command:

```bash
cd libs/mewnet
CGO_ENABLED=1 mise exec -- go build \
  -p=2 \
  -trimpath \
  -buildmode=c-shared \
  -ldflags "-s -w -X github.com/metacubex/mihomo/constant.Version=v1.19.33" \
  -o ../../dist/libmewnet.so \
  ./cmd/mewnet
```

C subscription library:

```bash
make subs
# dist/libmewnet.so — Go core + C subscriptions + SQLite in one library
# build/apps/mewnet-subs/mewnet-subs
```

SQLite is compiled into the library from the vendored amalgamation with
`SQLITE_THREADSAFE=1`, `SQLITE_DQS=0`, `SQLITE_DEFAULT_FOREIGN_KEYS=1`,
`SQLITE_ENABLE_MATH_FUNCTIONS` and **`SQLITE_ENABLE_FTS5`**; extension loading is
disabled. The flags live in `libs/mewnet/cmd/mewnet/cgo_flags.go`, so `make build`
and `make subs` produce the same feature set. Check a build with:

```bash
python3 -c "import ctypes; l=ctypes.CDLL('./dist/libmewnet.so'); \
l.sqlite3_compileoption_used.restype=ctypes.c_int; \
print(l.sqlite3_compileoption_used(b'ENABLE_FTS5'))"
```

GUI on Odin/raylib:

```bash
make gui
# build/mewnet-gui
```

Output:

- `dist/libmewnet.so` — the library;
- `dist/libmewnet.h` — header generated by cgo;
- `libs/mewnet/cmd/mewnet/mewnet.h` and `mewnet_types.h` — public headers
  (use these; `mewnet.h` includes `mewnet_types.h`).

`-p=2` limits parallelism: mihomo is large, and on machines with 1–2 GB of RAM a
build with a higher `-p` can fail on memory.

## Using from C

```bash
cc app.c -Ilibs/mewnet/cmd/mewnet -Ldist -lmewnet -Wl,-rpath,'$ORIGIN' -o app
```

`$ORIGIN` is needed so that `libmewnet.so` is found next to the binary. Otherwise
set `LD_LIBRARY_PATH=dist`.

## Using from Python

```python
import ctypes
lib = ctypes.CDLL("dist/libmewnet.so")
```

See `README.md` and `tests/python/test_api.py` for a complete example.

## Cross-compiling for Windows (mingw)

Requires `x86_64-w64-mingw32-gcc` (already present in the environment).

```bash
make build-mingw-core
# dist/windows/mewnet.dll
# dist/windows/libmewnet.dll.a
# dist/windows/mewnet.def

make subs-mingw
# dist/windows/mewnet.dll
# build-mingw/build/apps/mewnet-subs/mewnet-subs.exe
```

`subs-mingw` uses `cmake/toolchains/mingw-x86_64.cmake`.
Tests are not built on Windows (`MEWNET_SUBS_BUILD_TESTS=OFF`).
Running under Wine has not been tested.

## Tests

```bash
make test-unit       # Go task tests + basic ABI
make test-links      # SharedVPNLink without network
make test-stress     # 100 add/remove cycles
make test-c          # C header and linking
make xray            # download Xray to /tmp/opencode/xray
make test-e2e        # single VLESS + mixed inbound
make test-e2e-links  # 4 proxies, hot-swap, concurrent pings
make test-c-ping-local                 # ping from C through a local Xray
make test-c-ping MEWNET_TEST_VLESS='vless://...'  # ping from C through a real link
make test-subs       # C subscription tests (base64, SHA-256, rating)
make test-e2e-subs   # local Xray + HTTP subscription + SQLite/rating
```

## Notes

- TUN is not enabled: the build is without the `with_gvisor` tag;
- `dlclose` for the `.so` is forbidden — the Go runtime is not unloaded;
- one mihomo instance per process;
- glibc compatibility: built on Fedora 45 / glibc 2.44; for older
  distributions build in an older base image;
- distributing the `.so` requires compliance with GPL-3.0 (the mihomo license).

## Diagnostics

| Symptom | Cause |
|---|---|
| `mixed inbound failed to listen` | port busy, set `mixed_port: 0` |
| `mewnet is already initialized` | an instance already lives in the process; call `mewnet_shutdown` |
| `undefined reference to mewnet_*` | `-lmewnet` not linked or wrong `include` |
| `libmewnet.so: cannot open shared object file` | add `-Wl,-rpath` or `LD_LIBRARY_PATH` |
| e2e: `blocked target ... blackholing` | Xray 26.x blocks loopback; the test config has `finalRules: allow` |
