# milib GUI (Odin + raylib)

Простая GUI-программа для управления подписками и прокси из SQLite.

## Сборка и запуск

```bash
make gui
./build/milib-gui --db data/subs.db
```

GUI использует:

- `libmilib_subs` для всех операций с SQLite;
- `vendor:raylib` из Odin;
- только страницы прокси, а не всю подписку.

## Что можно делать

- добавить подписку: URL + priority;
- удалить выбранную подписку;
- смотреть список подписок;
- выбрать подписку и листать её прокси страницами по 16;
- видеть имя, протокол, адрес, рейтинг, alive/dead, задержку, manual-флаг;
- выбрать прокси и посмотреть полную share-ссылку;
- добавить ручной прокси в выбранную подписку;
- удалить выбранный прокси.

## Память

GUI **не загружает**:

- тело подписки;
- все прокси подписки;
- все прокси группы.

Он держит в памяти:

- список подписок (он обычно небольшой);
- одну страницу `milib_subs_proxy_summary` без полной ссылки;
- одну выбранную полную запись `milib_subs_proxy`.

Поэтому для подписки на 10 000 конфигов используется примерно тот же объём,
что и для 20.

## Библиотечные API для GUI

Добавлены в `libmilib_subs`:

- `milib_subs_load_proxy_summaries` / `milib_subs_unload_proxy_summaries`
  — страница без поля `link`;
- `milib_subs_get_proxy` — одна полная запись по id;
- `milib_subs_add_proxy` — ручной прокси в подписку (`manual = 1`);
- `milib_subs_remove_proxy`;
- `milib_subs_count_proxies`.

Ручные прокси не удаляются при следующем fetch, если их нет в подписке:
generation-cleanup удаляет только `manual = 0`.
